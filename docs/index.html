repo-storyteller is an ELI5 code explainer for AI coding agents. Ask it to explain a file, a function or a concept. It turns your repo into a story, traces every function call down to the bottom, and teaches the real engineering terms, including what breaks without them.

🧸 Story world

Your repo becomes a restaurant, a factory or a library, with characters that stay the same across every explanation.

🔍 Deep trace

It follows each call into your own functions all the way down, notes the inputs and outputs, and climbs back up. Every claim cites file:line.

🧩 Term cards

Every concept gets four parts: the story, what it really is, why it's needed here, and 💥 what breaks without it.

🌐 Interactive pages

A clickable flow map, expandable nested traces, annotated code, quizzes, a progress bar and dark mode.

🎢 Never boring

Hooks, cliffhangers, "predict what happens" quizzes, and a choose-your-next-path menu.

✏️ Excalidraw

If an Excalidraw MCP server is connected, it draws the call journey and term scenes for you.

FAQ

How is this different from just asking my agent "explain this code"?

Plain prompts give a flat summary. repo-storyteller forces a depth-first trace through every function on the path, cites real lines, explains each term with a concrete failure scenario, and produces a page you can come back to.

Does it work with Codex and OpenCode, not just Claude Code?

Yes. It follows the open Agent Skills SKILL.md standard and installs into each agent's skills folder via npx skills, the shell installer, or a manual copy.

Which languages does it support?

Any language your agent can read: Python, TypeScript, Go, Rust, Java and more. The trace follows imports and calls, whatever the language.
